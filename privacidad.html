Política de privacidad

Aplicación «Autotube» · en vigor desde el 19 de octubre de 2026

Autotube es una herramienta personal de línea de comandos que su autor ejecuta en su propio ordenador para gestionar su canal de YouTube. No tiene servidores, no publica ningún servicio en internet y no está dirigida a otros usuarios.

Qué datos se usan

Cuando una persona autoriza la aplicación con su cuenta de Google, Autotube accede, mediante las API de YouTube, a:

  • El canal de YouTube asociado a esa cuenta: nombre e identificador.
  • Los vídeos de ese canal: identificador, título, descripción, etiquetas, fecha de publicación, estado de privacidad y duración.
  • Las métricas de ese canal en YouTube Analytics: visitas, minutos reproducidos, duración media de visualización, fuentes de tráfico, suscriptores ganados y perdidos, y datos demográficos agregados que YouTube proporciona sin identificar a ninguna persona.

Autotube no accede al correo, a los contactos, a los archivos ni a ningún otro dato de la cuenta de Google, y no solicita permisos distintos de los enumerados en la página principal.

Para qué se usan

Exclusivamente para dos cosas: subir vídeos al canal de quien concede el permiso, y generar un informe de texto con la evolución de ese mismo canal. No se usan para ninguna otra finalidad, ni para publicidad, ni para elaborar perfiles.

Dónde se guardan

Los datos descargados se guardan en archivos CSV y de texto en el ordenador del autor. El testigo de acceso (token de OAuth) se guarda en un archivo local del mismo ordenador. Nada de esto se sube a ningún servidor ni se almacena en internet.

Con quién se comparten

Con nadie. Los datos no se venden, no se ceden, no se transfieren a terceros y no se publican. La aplicación solo se comunica con las API de Google necesarias para las funciones descritas.

Cuánto tiempo se conservan

Los archivos permanecen en el ordenador del autor mientras le resultan útiles para comparar periodos, y se borran manualmente cuando dejan de serlo. El token de acceso se borra al revocar el permiso o al eliminar el archivo.

Cómo retirar el acceso

Cualquier persona que haya autorizado la aplicación puede retirarle el permiso en cualquier momento desde la página de permisos de su cuenta de Google. A partir de ese momento la aplicación deja de poder acceder a sus datos. Para solicitar el borrado de los datos ya descargados, basta con escribir a la dirección de contacto.

Uso de los datos de las API de Google

El uso que Autotube hace de la información recibida de las API de Google se ajusta a la Política de Datos de Usuario de los Servicios de API de Google, incluidos sus requisitos de uso limitado.

Cambios

Si esta política cambia, la nueva versión se publicará en esta misma dirección, con su fecha de entrada en vigor.
